# SPEC.md

memoアプリ（Android向けネイティブメモアプリ）の機能仕様書。

## 画面/機能仕様

### メモ一覧
- タイトル・更新日時を表示
- ピン留め
- 検索
- 並び替え

### メモ編集
- タイトル・本文
- 自動保存、保存日時の更新
- 文字数表示
- Undo / Redo

### 削除
- ゴミ箱へ移動、30日間保持
- 完全削除
- 復元可能

### タグ
- 作成・編集・削除・検索
- 複数タグ付与

### お気に入り
- スター登録
- お気に入り一覧表示

### 検索
- 全文検索、タイトル検索、タグ検索
- 複合検索（条件の組み合わせ）

### 並び替え
- 更新日 / 作成日 / タイトル / お気に入り / ピン留め

### 表示設定
- ライト / ダーク / システム追従
- フォントサイズ変更
- 一覧表示の切替

### バックアップ
- JSONエクスポート / インポート
- ファイル選択、エラー処理

## UIデザイン
- Material Design 3
- 余白は8dpグリッド
- アニメーションは最小限
- レスポンシブ、タブレットでもレイアウトが崩れないこと
- アクセシビリティ対応、ダークモード対応

## データ設計
- Room Database、Entity設計、Index作成
- Migration対応、Version管理
- UIからのDB直接アクセス禁止（Repository経由のみ）
