# 1. このアプリでできること

## 1-1. アプリの概要

「TALK（トーク）」は、インターネットを通じて、はなれた場所にいる人とメッセージのやり取りができるチャットアプリです。みなさんがよくご存じの「LINE（ライン）」とよく似た使い心地で、文字のメッセージや写真、かわいいスタンプを送り合うことができます。

特別なソフトをパソコンに入れる必要はありません。インターネットを見るための画面（ブラウザ）さえあれば、すぐに使いはじめられます。

> **ブラウザとは？**
> インターネットのホームページを見るためのソフトのことです。たとえば「Google Chrome（グーグル クローム）」「Microsoft Edge（マイクロソフト エッジ）」「Safari（サファリ）」などがあります。パソコンやスマートフォンに最初から入っていることがほとんどです。

## 1-2. 利用シーン

このアプリは、こんな場面で活躍します。

| 利用シーン | 具体的な使い方 |
|------------|----------------|
| 仲間との連絡 | 数人のグループを作って、みんなで会話する |
| 写真の共有 | 撮った写真をその場で送って見せ合う |
| かんたんな返事 | スタンプ（絵文字の大きな絵）でサッと気持ちを伝える |
| 大事な連絡の確認 | 相手がメッセージを読んだかどうか（既読）を確認する |

## 1-3. 主な機能

このアプリでできる主なことは、次のとおりです。

- **メッセージの送受信** … 文字のメッセージを送ったり受け取ったりできます。
- **写真（画像）の送信** … スマートフォンやパソコンの中の写真を送れます。
- **スタンプの送信** … 大きな絵文字でかんたんに気持ちを伝えられます。
- **グループでの会話** … 「トーク」と呼ばれる部屋を作り、複数人で会話できます。
- **既読の確認** … 自分のメッセージを相手が読むと「既読」と表示されます。
- **リアクション** … 相手のメッセージに絵文字でかんたんに反応できます。
- **返信（リプライ）** … どのメッセージへの返事かをはっきりさせて返信できます。
- **通知** … 新しいメッセージが届くと、音やお知らせで教えてくれます。

> **ワンポイントアドバイス**
> このアプリは「リアルタイム」で動きます。つまり、相手がメッセージを送ると、こちらの画面にもすぐに表示されます。画面を更新（再読み込み）する必要はありません。届くのをそのまま待っていてくださいね。

# 2. 利用前の準備

## 2-1. 推奨環境（用意するもの）

このアプリを快適に使うために、次のものをご用意ください。

| 必要なもの | 説明 |
|------------|------|
| インターネット接続 | Wi-Fi（ワイファイ）や携帯電話の回線など |
| ブラウザ | Google Chrome、Microsoft Edge、Safari などの新しいバージョン |
| パソコン または スマートフォン | どちらでも利用できます |
| ログイン情報 | 「ユーザー名」と「パスワード」（次の項目で説明します） |

## 2-2. ログイン情報について（とても大切です）

このアプリは、ご自分で新規登録（アカウントの自己作成）をすることが**できません**。

アカウント（あなた専用の利用権）は、**管理者（このアプリを運営している担当者）が発行します**。利用をはじめる前に、管理者から次の2つを受け取ってください。

| 受け取るもの | 説明 | 例 |
|--------------|------|------|
| ユーザー名 | あなたを識別するための名前 | `tanaka` など |
| パスワード | 本人だけが知っている合いことば | （6文字以上の英数字など） |

> **メールアドレスは必要ありません**
> ふつうのアプリでは登録にメールアドレスが必要なことが多いですが、このアプリでは不要です。管理者からもらった「ユーザー名」と「パスワード」だけでログインできます。

ログインの前に、次のことを確認しておきましょう。

- [ ] インターネットにつながっているか

- [ ] 管理者から「パスワード」を受け取ったか
- [ ] アプリのURL（ホームページのアドレス）を知っているか

# 4. 基本操作

ここでは、毎日使う基本の操作を順番に説明します。まずはこの章をマスターすれば、ひととおりの会話ができるようになります。

## 4-1. ログイン（アプリに入る）

アプリを使いはじめるときの、いちばん最初の操作です。

### 操作手順

1. ブラウザを開き、アドレス欄にアプリのURLを入力して開きます。
2. ログイン画面が表示されます。
3. 「**ユーザー名**」の欄に、管理者からもらったユーザー名を入力します。
4. 「**パスワード**」の欄に、管理者からもらったパスワードを入力します。
5. 緑色の「**ログイン**」ボタンを押します。

【スクリーンショット】
表示内容：
（ログイン画面）
強調箇所：
（「ユーザー名」入力欄、「パスワード」入力欄、緑色の「ログイン」ボタンをそれぞれ赤枠で囲む）
説明文：
上から「ユーザー名」「パスワード」を入力し、緑色の「ログイン」ボタンを押します。

### 操作結果

ログインに成功すると、「トーク一覧画面」が表示されます。これでアプリを使う準備が整いました。

### 注意点

- ユーザー名やパスワードは、**大文字・小文字**も正確に入力してください。「A」と「a」は別の文字として扱われます。
- **パスワードを5回続けてまちがえると、安全のため15分間ログインできなくなります**（ロック）。あわてず、正しい情報を確認してから入力しましょう。
- 入力をまちがえると、画面に赤い文字でお知らせが表示されます。表示された内容をよく読んでください。

## 4-2. ログアウト（アプリから出る）

共用のパソコンを使っているときなど、利用を終えるときの操作です。

### 操作手順

1. 画面下のメニューから「**マイページ**」を押します（または右上の自分のアイコンを押します）。
2. 設定画面が開きます。下のほうへ画面をスクロールします。
3. 赤い文字の「**ログアウト**」を押します。

### 操作結果

ログアウトすると、最初のログイン画面に戻ります。次に使うときは、もう一度ログインしてください。

### 注意点

- 自分専用のパソコンやスマートフォンであれば、毎回ログアウトする必要はありません。次回はログインした状態のまま使えます。
- **他の人と共用している機器では、必ずログアウト**してください。あなたのメッセージが他の人に見られてしまうのを防ぐためです。

## 4-3. 検索（会話やメッセージを探す）

### トーク一覧の中から部屋を探す

トーク一覧画面の上部にある虫めがねマーク（🔍）を押すと、部屋を探せます。

### 会話の中からメッセージを探す

1. メッセージを探したい部屋（チャット画面）を開きます。
2. 上部の虫めがねマーク（🔍）を押します。
3. 入力欄が出てくるので、探したい言葉を入力します。
4. その言葉を含むメッセージに、**黄色いマーカー**が付いて見つけやすくなります。

【スクリーンショット】
表示内容：
（チャット画面で検索バーを開き、言葉を入力した状態）
強調箇所：
（上部の検索入力欄と、黄色くマークされたメッセージを赤枠で囲む）
説明文：
探したい言葉を入力すると、その言葉が黄色く強調されて表示されます。

### 注意点

- 検索を終わりたいときは、もう一度虫めがねマークを押すと、検索の欄が閉じます。

## 4-4. 登録（新しいトークを作る）

新しい会話の部屋を作る操作です。くわしくは「5. 機能別の使い方」でも説明します。

### 操作手順

1. トーク一覧画面の上部にある「＋」ボタンを押します。
2. 「トーク名」の欄に、部屋の名前を入力します。
3. 「**作成**」ボタンを押します。

### 操作結果

新しい部屋が作られ、その部屋のチャット画面が開きます。

## 4-5. 編集（名前や写真を変える）

自分の表示名やプロフィール写真を変える操作です。くわしくは「5. 機能別の使い方」で説明します。

- 設定（マイページ）画面で、表示名やプロフィール写真を変更できます。

## 4-6. 削除（メッセージやアカウントを消す）

### 自分が送ったメッセージを削除する

1. 削除したい**自分の**メッセージを長押し（パソコンでは右クリック）します。
2. 出てきたメニューから「**削除**」を押します。
3. 「このメッセージを削除しますか？」と確認が出るので「OK」を押します。

### 注意点

- 削除できるのは、**自分が送ったメッセージだけ**です。相手のメッセージは削除できません。
- 一度削除したメッセージは元に戻せません。よく確認してから削除しましょう。

> **ワンポイントアドバイス**
> 操作に困ったら、まず画面のいちばん上か下を見てください。「戻る（←）」ボタンや下部メニューを使えば、いつでも安全な画面に戻れます。まちがった画面に行ってしまっても、あわてる必要はありません。

# 5. 機能別の使い方

ここからは、ひとつひとつの機能をくわしく説明します。必要なところだけ読んでも大丈夫です。

## 5-1. メッセージを送る

### 機能概要

文字のメッセージを相手に送る、いちばん基本の機能です。

### 操作手順

1. トーク一覧から、メッセージを送りたい部屋を押して開きます。
2. 画面下の「**メッセージを入力**」と書かれた欄を押します。
3. 送りたい文章を入力します。
4. 右端の紙飛行機マーク（✈）を押します。

【スクリーンショット】
表示内容：
（チャット画面の下部入力欄に文字を入力した状態）
強調箇所：
（文字を入力した入力欄と、右端の紙飛行機の送信ボタンを赤枠で囲む）
説明文：
メッセージを入力し、右端の紙飛行機ボタンを押すと送信できます。

### 操作結果

送信したメッセージが、画面の右側に緑色の吹き出しで表示されます。送信中は小さなくるくる回るマークが出て、送り終わるとチェックマーク（✓）が付きます。

### 注意点

- **パソコンの場合** … キーボードの「Enter（エンター）」キーでも送信できます。文章の途中で改行したいときは「Shift（シフト）」キーを押しながら「Enter」を押します。
- **スマートフォンの場合** … 「Enter」キーは改行になります。送信は必ず紙飛行機ボタンを押してください（あやまって送ってしまうのを防ぐためです）。
- 何も入力していないときは、送信ボタンは押せません（うすい色になっています）。

## 5-2. スタンプ（大きな絵文字）を送る

### 機能概要

文字を打たなくても、大きな絵文字でかんたんに気持ちを伝えられる機能です。

### 操作手順

1. チャット画面の下部にある、顔マーク（😊）を押します。
2. スタンプの一覧（😂 😍 👍 ❤️ など）が表示されます。
3. 送りたいスタンプを押します。

### 操作結果

選んだスタンプが、大きな絵としてメッセージに表示されます。

### 注意点

- スタンプは押すとすぐに送信されます。確認のメッセージは出ませんので、押しまちがいにご注意ください。
- スタンプの一覧を閉じたいときは、もう一度顔マークを押します。

## 5-3. 写真（画像）を送る

### 機能概要

スマートフォンやパソコンの中にある写真を、相手に送る機能です。

### 操作手順

1. チャット画面の下部、左端にある写真マーク（🖼）を押します。
2. 機器の中の写真を選ぶ画面が開きます。
3. 送りたい写真を1枚選びます。
4. 自動的にアップロード（送信の準備）が始まり、送信されます。

【スクリーンショット】
表示内容：
（チャット画面の入力欄、左端の写真ボタン）
強調箇所：
（左端の写真マークのボタンを赤枠で囲む）
説明文：
左端の写真マークを押すと、機器の中の写真を選んで送ることができます。

### 操作結果

選んだ写真が、メッセージとして吹き出しの中に表示されます。表示された写真を押すと、画面いっぱいの大きな表示で見ることができます（もう一度押すか、右上の×で閉じます）。

### 注意点

- 写真の大きさ（容量）は、**10MB（メガバイト）まで**です。これより大きい写真を選ぶと「画像は10MB以下にしてください」と表示され、送れません。
- 送信中は少し時間がかかることがあります。くるくる回るマークが消えるまでお待ちください。

## 5-4. メッセージにリアクション（絵文字で反応）する

### 機能概要

相手のメッセージに対して、わざわざ返信を書かなくても、絵文字でかんたんに「いいね」などの反応を伝えられる機能です。

### 操作手順

1. 反応したいメッセージを長押し（パソコンでは右クリック）します。
2. 絵文字のメニュー（👍 ❤️ 😂 😮 😢 🙏）が表示されます。
3. 付けたい絵文字を押します。

### 操作結果

メッセージの下に、選んだ絵文字と人数が小さく表示されます。同じ絵文字をもう一度押すと、自分の反応を取り消せます。

### 注意点

- 自分が付けた反応は、緑色のふちどりで表示されるので、ひと目でわかります。

## 5-5. メッセージに返信（リプライ）する

### 機能概要

たくさんの会話が流れているときに、「どのメッセージへの返事か」をはっきりさせて返信できる機能です。

### 操作手順

1. 返信したいメッセージを長押し（パソコンでは右クリック）します。
2. メニューから「**返信**」を押します。
3. 入力欄の上に、返信先のメッセージの一部が表示されます。
4. ふだんどおりメッセージを入力して送信します。

### 操作結果

送ったメッセージの上に、どのメッセージへの返信かが小さく表示され、会話の流れがわかりやすくなります。

### 注意点

- 返信をやめたいときは、入力欄の上に出ている返信先表示の「×」を押すと取り消せます。

## 5-6. 新しいトーク（部屋）を作る

会話をするための新しい部屋を作る機能です。作った人がオーナー（部屋の持ち主）になります。

4. 必要であれば「メンバーを招待」で、いっしょに会話する人を選びます（あとからでも追加できます）。
5. 「**作成**」ボタンを押します。

【スクリーンショット】
表示内容：
（「新しいトークを作成」の入力画面）
強調箇所：
（「トーク名」入力欄と、緑色の「作成」ボタンを赤枠で囲む）
説明文：
トーク名を入力し、「作成」ボタンを押すと新しい部屋ができます。

## 5-7. トーク（部屋）に招待する／参加する

### 機能概要

ほかの人を会話の部屋に招く機能です。「招待リンク」を送る方法と、ユーザーを直接追加する方法があります。

### 招待リンクで招く（オーナー・管理者の操作）

2. 「**メンバー管理・招待**」を押します。
3. 「招待リンクを生成」を押すと、招待用のリンク（URL）が作られます。
4. 「**リンクをコピー**」を押して、そのリンクをメールやほかの方法で相手に送ります。

【スクリーンショット】
表示内容：
（メンバー管理パネルの招待リンク部分）
強調箇所：
（生成された招待リンクと「リンクをコピー」ボタンを赤枠で囲む）
説明文：
「招待リンクを生成」でリンクを作り、「リンクをコピー」で相手に送ります。

1. 受け取った招待リンク（URL）を押して開きます。

- 招待リンクを作ったり、メンバーを直接追加できるのは、部屋の「オーナー」または「管理者」だけです。

## 5-8. メンバーを管理する（オーナー・管理者の操作）

### 機能概要

部屋に参加している人の一覧を見たり、役割を変えたり、退出させたりする機能です。部屋の中での立場（役割）には3種類あります。

| 役割 | 説明 | できること |
|------|------|------------|
| オーナー | 部屋を作った人 | すべての操作（メンバー追加・退出・役割変更・名前変更） |
| 管理者 | オーナーから任命された人 | メンバーの追加・退出、招待リンク作成、名前変更 |
| メンバー | ふつうの参加者 | 会話への参加 |

### 操作手順

1. チャット画面の右上、点が3つ（⋮）のメニューを押します。
2. 「**メンバー管理・招待**」を押します。
3. 参加メンバーの一覧が表示されます。
4. 各メンバーの横のボタンで、次の操作ができます。
   - 「**管理者**」… そのメンバーを管理者にします（オーナーのみ）。
   - 「**解除**」… 管理者を、ふつうのメンバーに戻します（オーナーのみ）。
   - 「**退出**」… そのメンバーを部屋から外します。

### 注意点

- オーナー自身を退出させたり役割を変えたりすることはできません。
- メンバーを退出させるときは、確認のメッセージが表示されます。よく確認してから操作してください。

## 5-9. グループ名（部屋の名前）を変える

### 機能概要

会話の部屋の名前を、あとから変える機能です（オーナー・管理者のみ）。

### 操作手順

### 操作結果

部屋の名前が新しいものに変わり、全員の画面に反映されます。

## 5-10. 通知をミュート（一時的に止める）する

### 機能概要

特定の部屋について、新しいメッセージのお知らせ（音やポップアップ）を出さないようにする機能です。会議中など、通知を止めたいときに便利です。

### 注意点

## 5-15. アカウントを削除（退会）する

# 6. よくある質問（FAQ）

利用者の方からよく寄せられる質問とその答えをまとめました。

### Q1. アカウントは自分で作れますか？

いいえ、作れません。このアプリのアカウントは管理者が発行します。利用したい場合は、管理者に「ユーザー名」と「パスワード」を発行してもらってください。

### Q2. メールアドレスは必要ですか？

必要ありません。管理者からもらった「ユーザー名」と「パスワード」だけでログインできます。

### Q3. パスワードを忘れてしまいました。どうすればいいですか？

ご自分でパスワードを変えることはできません。管理者にお問い合わせのうえ、新しいパスワードを発行してもらってください。

### Q4. ログインのときに「ユーザー名」を入力する欄がありますが、大文字・小文字は区別されますか？

はい、区別されます。「Tanaka」と「tanaka」は別のものとして扱われますので、管理者からもらったとおりに正確に入力してください。

### Q5. メッセージを送ったのに、相手に「既読」が付きません。

相手がまだそのメッセージを開いて読んでいない状態です。相手がメッセージを読むと、自動的に「既読」と表示されます。しばらくお待ちください。

### Q6. 送ったメッセージを取り消せますか？

はい、自分が送ったメッセージは削除できます。メッセージを長押し（パソコンでは右クリック）して、「削除」を選んでください。ただし、相手のメッセージは削除できません。

### Q7. 写真は何枚でも、どんな大きさでも送れますか？

写真は1回に1枚ずつ送れます。1枚あたりの大きさは10MBまでです。これより大きい写真は送れませんので、その場合は写真の容量を小さくしてからお試しください。

### Q8. 「VOOM」や「ニュース」「ウォレット」は何ですか？

これらは将来のために用意されている入口で、現在はまだ使えません。ふだんは「トーク」と「マイページ」の2つを使えば大丈夫です。

### Q9. 通知（お知らせ）が来ません。どうすればいいですか？

設定（マイページ）画面で「通知を有効にする」を押し、ブラウザの確認で「許可」を選んでください。また、その部屋の通知を「ミュート」にしていないかもご確認ください。

### Q10. 招待リンクを送ったのに、相手が参加できないと言っています。

招待リンクは作ってから7日間だけ有効です。期限が切れている可能性がありますので、もう一度新しい招待リンクを作って送ってください。

### Q11. スマートフォンとパソコンの両方で使えますか？

はい、どちらでも使えます。同じユーザー名とパスワードでログインすれば、同じ会話を見ることができます。

### Q12. 画面が暗い色（または明るい色）になってしまいました。元に戻せますか？

はい。設定（マイページ）画面の「テーマ」で「ライト」（明るい）か「ダーク」（暗い）を選び直せば、好きな色に変えられます。

### Q13. 間違えてアカウントを削除してしまいました。元に戻せますか？

申し訳ありませんが、削除したアカウントは元に戻せません。再び利用するには、管理者に新しいアカウントを発行してもらう必要があります。

> **ワンポイントアドバイス**
> ここに載っていない疑問があるときは、次の「7. トラブルシューティング」も合わせてご覧ください。それでも解決しないときは、管理者にお問い合わせいただくのがいちばんの近道です。

# 7. トラブルシューティング（困ったときは）

操作中に困ったことが起きたときの、解決のヒントをまとめました。あわてず、上から順番に試してみてください。

## 7-1. ログインできない

| 症状 | 考えられる原因 | 対処方法 |
|------|----------------|----------|
| 「ユーザー名またはパスワードが正しくありません」と出る | 入力まちがい | 大文字・小文字を含め、もう一度ていねいに入力する |
| 「あと1回失敗するとロックされます」と出る | 何度もまちがえている | これ以上まちがえないよう、正しい情報を確認してから入力する |
| 「ログインが連続5回失敗しました」と出る | 5回まちがえてロックされた | 表示された時間（15分ほど）待ってから、もう一度試す |
| 「このアカウントは停止されています」と出る | 管理者が利用を停止している | 管理者にお問い合わせください |

**それでも入れないときは：** 管理者に連絡し、ユーザー名とパスワードが正しいか確認してもらってください。

## 7-2. データ（会話やメッセージ）が表示されない

| 症状 | 対処方法 |
|------|----------|
| 「読み込み中...」のまま進まない | インターネットの接続を確認し、しばらく待つ |
| トークが1つも表示されない | まだ部屋に参加していない可能性があります。「＋」から作るか、招待してもらってください |
| 画面が真っ白になる | ブラウザの再読み込み（更新）を行ってください |

**ページの再読み込み（更新）のしかた：**
- パソコン … キーボードの「F5」キーを押す、またはアドレス欄の横の更新ボタン（丸い矢印）を押す
- スマートフォン … 画面を上から下に軽く引っぱる、または更新ボタンを押す

## 7-3. メッセージが送れない・保存できない

| 症状 | 対処方法 |
|------|----------|
| 送信ボタンが押せない（うすい色） | メッセージが何も入力されていません。文字を入力してください |
| メッセージに赤い枠と「⟳ 再送」が出た | 送信に失敗しています。インターネット接続を確認し、「⟳ 再送」を押す |
| 写真が送れない | 写真が10MBを超えていないか確認してください |
| 設定の保存ができない | 表示名が空になっていないか確認してください |

> **「⟳ 再送」について**
> メッセージの送信に失敗すると、そのメッセージに赤い枠が付き、「⟳ 再送」と表示されます。これを押すと、もう一度送信を試みます。電波の悪い場所などで起こりやすいので、電波の良い場所で再送してみてください。

## 7-4. エラーのお知らせが表示された

画面に赤い文字でお知らせ（エラー）が出たときは、あわてずにその内容を読んでください。よく出るお知らせと対処方法は次のとおりです。

| 表示されるお知らせ | 意味 | 対処方法 |
|--------------------|------|----------|
| 画像は10MB以下にしてください | 送ろうとした写真が大きすぎる | 小さい写真を選ぶ |
| 画像は5MB以下にしてください | プロフィール写真が大きすぎる | 小さい写真を選ぶ |
| 招待リンクが無効または期限切れです | 招待リンクの7日間の期限が切れた | 新しい招待リンクを作ってもらう |
| 参加に失敗しました | 部屋に入れなかった | 「再試行」を押す、または管理者に連絡 |
| 削除に失敗しました | 通信などの問題 | 少し時間をおいて、もう一度試す |

## 7-5. 通知（お知らせ）が来ない

次の順番で確認してください。

1. 設定（マイページ）画面で「通知を有効にする」を押しましたか？
2. ブラウザの確認で「許可」を選びましたか？
3. その部屋の通知を「ミュート」にしていませんか？（チャット画面の⋮メニューで確認）
4. お使いの機器（スマートフォンなど）自体の通知設定がオフになっていませんか？

## 7-6. その他、解決しないとき

ここまで試しても問題が解決しないときは、次の方法をお試しください。

1. **ページを再読み込み（更新）する** … 多くの問題はこれで解決します。
2. **一度ログアウトして、もう一度ログインする** … 表示が正しくなることがあります。
3. **別のブラウザで開いてみる** … ブラウザ特有の問題かどうかを切り分けられます。
4. **インターネット接続を確認する** … Wi-Fiや電波の状態を確認してください。
