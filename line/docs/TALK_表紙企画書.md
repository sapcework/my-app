**この企画書について**

この企画書は、「TALK（トーク）操作説明書」を一冊の本（解説書）として仕立てるための、表紙まわりのデザイン案をまとめたものです。市販のパソコン解説書や業務システム入門書のような、手に取りやすく読みたくなる装丁を想定しています。タイトル案、キャッチコピー、表紙・背表紙・裏表紙のデザイン指示、そして画像生成AI向けのプロンプトまでを収録しています。

> **装丁（そうてい）とは？**
> 本の表紙やデザイン、見た目全体のことです。中身が同じでも、装丁が親しみやすいと「読んでみよう」という気持ちになります。

# 3. キャッチコピー案

表紙の上部（タイトルより上）に置く、短く目を引く一言です。帯（おび）のように使ってもよいでしょう。

### メインキャッチ（1つ選んで大きく配置）

- **はじめてでも、ぜんぶわかる。**
- **読んだその日から、使える。**
- **むずかしい言葉は、使いません。**
- **画面を見ながら、迷わず操作。**

### サブキャッチ（複数を小さく並べて配置）

- ✓ はじめてでも安心
- ✓ すぐに使える
- ✓ 新人教育にも最適
- ✓ 専門用語ゼロ
- ✓ 画面写真でわかりやすい
- ✓ 困ったときのQ&A付き

> **ワンポイント**
> キャッチコピーは「短く・やさしく・前向きに」が鉄則です。長い説明より、ひと言の安心感のほうが手に取ってもらえます。

# 4. 表紙デザイン指示

画像生成AIやデザイナーに依頼するための、具体的なデザイン指示です。

## 4-1. 全体コンセプト

書店のパソコン入門書コーナーに並んでいても違和感のない、**清潔感のある明るいデザイン**。「やさしそう」「自分にもできそう」と感じてもらえることを最優先にします。難しそう・かたそうな印象は避けます。

## 4-2. レイアウト（要素の配置）

| 位置 | 配置する要素 |
|------|--------------|
| 上部（10%） | キャッチコピー（細めの文字・帯状の背景があってもよい） |
| 上〜中央（35%） | 大きなメインタイトル＋その下にサブタイトル |
| 中央〜下（45%） | メインのイラスト（スマホでチャットする人物など） |
| 最下部（10%） | 「操作説明書」「対応バージョン v0.0.1」などの小さな表記 |

- 全体は**縦長（A4縦またはB5縦）**を基本とします。
- 余白をたっぷりとり、ごちゃごちゃさせないこと。

## 4-3. 配色

アプリのカラーに合わせ、親しみやすく清潔な配色にします。

| 用途 | 色 | カラーコード |
|------|------|------------|
| メインカラー | やさしい緑（アプリと同じ） | `#4CAF50` |
| アクセント | 明るい黄緑〜ライム | `#8BC34A` |
| 背景 | 白〜ごく薄い水色 | `#FFFFFF` 〜 `#EAF6FB` |
| 補助 | 空のような淡い青 | `#B2D8EA` |
| 文字 | 濃いグレー（黒すぎない） | `#333333` |

- 全体に**白基調＋緑のアクセント**で、明るく軽やかにまとめます。
- 原色を多用せず、やわらかいトーンで。

## 4-4. イラストの雰囲気

- **フラットデザイン**（影を抑えた、平面的でシンプルな現代風イラスト）。
- やさしい線・丸みのある形。とがった印象を避ける。
- 笑顔の人物（年齢・性別を問わず、幅広い層が自分を重ねられる）が、スマートフォンやノートパソコンでチャットを楽しんでいる様子。
- 吹き出し（メッセージのフキダシ）、緑のチャット画面、ハートや「いいね👍」などのリアクションが、楽しげに飛び交うイメージ。
- 過度にリアルでなく、親しみやすいイラストタッチ。

## 4-5. アイコン・モチーフ

表紙に散りばめる小物（モチーフ）として、次を活用します。

- 吹き出し（💬 メッセージのフキダシ）
- 紙飛行機（✈ 送信を象徴）
- スマートフォンの画面
- 笑顔の絵文字・スタンプ（😊 👍 ❤️）
- 緑のチェックマーク（✓ 既読・安心の象徴）

## 4-6. フォントイメージ

| 要素 | フォントの雰囲気 |
|------|------------------|
| タイトル | 太めの丸ゴシック（やわらかく、力強すぎない）。可読性最優先 |
| サブタイトル | 細めのゴシック。すっきりと |
| キャッチコピー | 手書き風、または親しみのある丸ゴシック |
| 補足表記 | 標準的なゴシック・小さめ |

- 明朝体（とめ・はねのある書体）は使わず、**丸みのあるゴシック体**で統一し、やさしさと読みやすさを出します。

## 4-7. ターゲット層

- パソコン・スマートフォンの操作に不慣れな一般の方
- 業務システムをはじめて使う新入社員・スタッフ
- 専門用語が苦手な方
- 幅広い年齢層（若年〜シニアまで）

## 4-8. 完成度の基準

- 書店のIT入門書コーナーに陳列されていても通用するプロ品質。
- 印刷して配布できる解像度（300dpi以上）・CMYK想定。
- 一目で「初心者向けのやさしい本」とわかること。

# 7. 裏表紙

本の裏側です。「この本を買おう（読もう）」と思ってもらうための、紹介スペースです。

## 7-1. 本の紹介文（リード文）

> **「むずかしそう」は、もう終わりです。**
>
> この本は、チャットアプリ「TALK（トーク）」を、はじめて使う方のためのやさしい操作ガイドです。ログインのしかたから、メッセージや写真の送り方、困ったときの対処法まで、すべて画面写真つきで、ていねいに説明しています。
>
> 専門用語は使いません。書いてあるとおりに画面を進めるだけで、いつのまにか使いこなせるようになります。「自分にもできた！」という喜びを、ぜひ味わってください。

## 7-2. 対象読者

この本は、こんな方におすすめです。

- パソコン・スマートフォンの操作に不慣れな方
- はじめて「TALK」を使う方
- 専門用語が苦手な方
- 新しく業務システムを使うことになった新入社員・スタッフの方
- 家族や同僚に使い方を教える立場の方

## 7-3. この本で学べること

- アプリへのログイン・ログアウトのしかた
- メッセージ・写真・スタンプの送り方
- グループ（トーク）の作り方・招待のしかた
- 既読・リアクション・返信などの便利な機能
- 通知やプロフィール、画面の色の設定方法
- ログインできない・送れないなど、困ったときの対処法

## 7-4. おすすめポイント

| ポイント | 内容 |
|----------|------|
| 🟢 全手順に画面写真 | どこを押すか、赤枠でひと目でわかる |
| 🟢 専門用語ゼロ | むずかしい言葉には、やさしい説明つき |
| 🟢 Q&A・困りごと対応 | よくある質問と解決法をたっぷり収録 |
| 🟢 そのまま研修に | 新人教育・社内配布の教材として使える |
| 🟢 迷わない構成 | 知りたいところから読める章立て |
