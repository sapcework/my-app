# FxFetch.xlsm（為替CSV作成ツール）

Excel のボタン1つで、25通貨ペアの日足CSVを作成します。形式は `fdata/csv/` と同じです（ヘッダなし・`日付,始値,高値,安値,終値`・LF改行・JPYは小数3桁/他は5桁）。
中身は `fdata/fetch_latest.py` と同じ処理で、同時に実行した場合の出力は完全に一致することを確認済みです。

## 必要なもの
- **Windows 版 Excel**（2010 以降、32bit・64bit どちらでも可）。Mac 版 Excel では動きません。
- インターネット接続（Yahoo Finance から取得します）
- Python などの追加インストールは不要です。

## 別のPCでの使い方
1. `FxFetch.xlsm` を好きなフォルダにコピーします。
2. ネットやメールから受け取った場合は、ファイルを右クリック →［プロパティ］→ 下にある「許可する」（ブロックの解除）にチェックを入れて［OK］を押します。これをしないと、マクロがブロックされて動きません。
3. 開いて、上に出る黄色いバーの［コンテンツの有効化］を押します。
4. 開いたときに、ブックと同じ場所に `csv` フォルダが自動で作られ、B2 にそのパスが入ります。別の場所に出力したいときは、B2 を書き換えるか［参照…］で選んでください（次に開いたときは、また `csv` フォルダに戻ります）。
5. ［CSVを作成］を押します。30秒ほどで完了のメッセージが出ます。

## シートの項目
| セル | 内容 |
|---|---|
| B2 | 出力フォルダ。開いたときにブックと同じ場所の `csv` が入ります。存在しない場合は実行時に自動で作ります |
| B3 | 本数（初期値 200 営業日） |
| A8 以下 | ペア名。行を足したり消したりして、対象を変えられます |
| B8 以下 | Yahoo のシンボル。CSV のファイル名にもなります。CNHJPY は Yahoo に履歴がないため CNYJPY にしてあります |
| D8 以下 | 実行結果。エラーのときはここに理由が出ます |

## 実行する時間
データが確定するのは**日本時間の朝6時**（米国冬時間の11月第1日曜〜3月第2日曜は**朝7時**）です。余裕を見て、その1時間後以降に実行してください。土・日・月曜の朝は、金曜分が最新です。

## うまくいかないとき
- **D列に「HTTP 404」**: B列のシンボルが間違っています。
- **D列に「HTTP 429」や接続エラー**: Yahoo 側の一時的な制限か、ネット接続の問題です。少し時間をおいて再実行してください。
- **会社のネットワークなどプロキシ経由の環境**: このツールは WinHTTP で通信するため、ブラウザのプロキシ設定は使われません。管理者に `netsh winhttp import proxy source=ie` の実行を依頼してください。
- 1ペアでも取得に失敗した場合は、日付がそろわなくなるため、CSV は1つも作りません。
- **D2 に「csv フォルダを作れませんでした」**: OneDrive 上のブックや、書き込みできない場所で開いています。［参照…］で出力先を選ぶか、ブックをローカルのフォルダにコピーしてから開いてください。

## 開発者向け
- `FxFetch.bas`: VBA のソースです。**CP932（Shift_JIS）・CRLF** で保存してください（UTF-8 だと取り込み時に日本語が化けます）。
- `build_xlsm.ps1`: `.bas` から `FxFetch.xlsm` を作り直します。実行中だけ、Excel の［トラスト センターの設定］→［マクロの設定］→「VBA プロジェクト オブジェクト モデルへのアクセスを信頼する」をオンにする必要があります。
- 画面に何も出さずに実行する入口として、`CreateCsvQuiet(出力フォルダ)` があります。結果のメッセージを返すので、自動実行に使えます。
