# LumiNote 仕様書（初心者向け）

このドキュメントは、メモアプリ「LumiNote」がどんなアプリで、どういう仕組みで動いているかを、
プログラミング初心者の方にもわかるように説明したものです。

---

## 1. このアプリは何？

**LumiNote** は、シンプルなメモ帳アプリです。有名な「Simplenote」というアプリを参考に作りました。

特徴は次の3つです。

| 特徴 | 意味 |
|------|------|
| **オフライン・ファースト** | インターネットが無くても使えます。書いたメモはまず自分の端末に保存されます。 |
| **クラウド同期** | ログインすると、メモが自動でクラウド（インターネット上の保管庫）に保存され、別の端末でも同じメモが見られます。 |
| **Web + デスクトップ対応** | ブラウザでも、Windows/Mac のアプリ（デスクトップ版）でも使えます。 |

> **「オフライン・ファースト」とは？**
> 多くのアプリは「ネットにつながっていないと使えない」作りですが、このアプリは逆です。
> 「まず自分の端末に保存 → 余裕があればクラウドにも同期」という順番なので、電波が悪くてもストレスなく使えます。

## 2. できること（機能一覧）

- 📝 **メモの作成・編集・削除**
- 🔍 **検索**（タイトル・本文から探す）
- 📌 **ピン留め**（大事なメモを一番上に固定）
- 🗑️ **ゴミ箱**（削除したメモを復元できる／完全削除もできる）
- ↕️ **並べ替え**（更新日・作成日・名前の6種類）
- 🔤 **文字サイズ変更**（極小〜特大の5段階）
- 🌙 **ダークモード**（ライト／システム／ダーク）
- ☁️ **クラウド同期**（ログイン時のみ）
- 📤 **エクスポート／インポート／CSV出力**（バックアップ）
- 🔒 **パスコードロック + 暗号化**（4桁の暗証番号で保護）

## 3. 画面の説明

アプリは大きく「**一覧**」と「**エディタ（編集画面）**」の2つに分かれています。

```
┌─────────────┬───────────────────────────┐
│  メモ一覧     │   エディタ（編集画面）        │
│             │                           │
│ ≡  [検索...] │  ← 戻る  タイトル    📌  ⓘ  │
│ ─────────── │  ─────────────────────────│
│ ・買い物リスト │  タイトルを入力             │
│ ・アイデア    │  ───────────────────────  │
│ ・日記       │  本文をここに書く…          │
│             │                           │
│      [＋]   │  保存済み           [削除]  │
└─────────────┴───────────────────────────┘
```

### メモ一覧（左側）
- **≡（三本線）** … メニューを開く（設定・ゴミ箱など）
- **検索ボックス** … メモを探す
- **＋ボタン** … 新しいメモを作る
- メモをタップ／クリックすると、右側の編集画面が開きます。

### エディタ（右側）
- **← 戻る** … 一覧に戻る（※何も書いていない空のメモは自動で捨てられます）
- **📌（ピン）** … このメモを一覧の一番上に固定
- **ⓘ（情報）** … 同期状態・更新日・作成日を表示
- **削除** … メモをゴミ箱へ移動

> メモは「自動保存」です。保存ボタンを押す必要はありません。入力をやめると自動で保存されます。

## 4. 使われている技術（技術スタック）

「スタック」とは、アプリを作るために積み重ねた技術の組み合わせのことです。

| 技術 | 役割 | かんたんな説明 |
|------|------|--------------|
| **Next.js** | 画面の土台 | React というライブラリを使いやすくした、Web画面を作る道具 |
| **TypeScript** | プログラミング言語 | JavaScript に「型（データの種類）」のチェックを足した言語。バグを防げる |
| **IndexedDB** | ブラウザ内の保存場所 | ブラウザに内蔵された小さなデータベース（メモ帳の保管庫） |
| **Tauri** | デスクトップ化 | Web画面を Windows/Mac アプリに変える道具（軽い） |
| **Supabase** | クラウドのデータベース | インターネット上の保管庫＋ログイン機能 |
| **Tailwind CSS** | 見た目（デザイン） | クラス名を付けるだけで装飾できるCSSの道具 |

## 5. 全体の仕組み（アーキテクチャ）

アプリの中では、データが次のような順番で流れます。

```
  あなたの操作
      │
      ▼
 ┌─────────┐   画面（UI）
 │   UI    │   ボタンや文字入力
 └─────────┘
      │
      ▼
 ┌──────────────────┐  保存のまとめ役
 │ StorageProvider  │  「どこに保存するか」を切り替える
 └──────────────────┘
      │
      ▼
 ┌──────────────────┐  暗号化レイヤー
 │ Encrypted層       │  パスコードONなら本文を暗号化
 └──────────────────┘
      │
      ▼
 ┌──────────────────┐  端末への保存
 │ IndexedDB / Tauri │  ブラウザ or ファイルに保存
 └──────────────────┘
      │
      ▼
 ┌──────────────────┐  同期エンジン（裏方）
 │  Sync Engine     │  あとからクラウドへ送る
 └──────────────────┘
      │
      ▼
 ┌──────────────────┐  クラウド
 │   Supabase       │  インターネット上の保管庫
 └──────────────────┘
```

### 大事なルール
1. **画面（UI）はクラウドに直接アクセスしない。** 必ず「保存のまとめ役」を通します。
   こうすると、保存先を変えたいときに画面側を直さなくて済みます。
2. **まず端末に保存。クラウド同期はあとから（裏で）。** だからオフラインでも快適です。

## 6. メモのデータ構造

1つのメモは、次のような「箱」に入っています。

```ts
type Note = {
  id: string         // メモを区別するための番号（自動でつく）
  title: string      // タイトル
  content: string    // 本文
  createdAt: number  // 作成した日時
  updatedAt: number  // 最後に更新した日時
  version: number    // 何回更新したかの回数
  userId?: string    // 誰のメモか（ログイン時）
  pinned?: boolean   // ピン留めしているか
  deleted?: boolean  // ゴミ箱に入っているか
  deletedAt?: number // ゴミ箱に入れた日時
}
```

> **ポイント：削除しても、すぐには消えません。**
> 「削除」を押すと、実際には消さずに `deleted = true`（ゴミ箱フラグ）を立てるだけです。
> これを **論理削除** と呼びます。こうすることで、別の端末にも「このメモは削除された」という
> 情報が同期で正しく伝わり、ゴミ箱から復元することもできます。

## 7. 同期（シンク）の仕組み

「同期」とは、端末のメモとクラウドのメモを同じ内容にそろえることです。

### ルール：Last Write Wins（最後に書いた人が勝ち）
2つの端末で同じメモを編集したとき、**更新日時（updatedAt）が新しい方を採用**します。

```
端末A：14:00 に「買い物」と編集
端末B：14:05 に「買い物リスト」と編集
        ↓
クラウドには 14:05 の「買い物リスト」が残る（新しい方が勝ち）
```

### 同期のタイミング
- **アプリ起動時**：必ず1回、クラウドと照らし合わせます。
- **メモを編集したとき**：2秒待ってから、まとめてクラウドへ送ります（連打で送りすぎない工夫）。
- **失敗したとき**：時間を空けながら自動で再挑戦します（1秒 → 2秒 → 4秒…最大30秒間隔）。
  1件失敗しても他のメモの同期は止まりません。
- **手動再同期**：エディタの ⓘ → 「再同期」ボタンでいつでも実行できます。

> 同期はログインしているときだけ動きます。ログインしていなければ、メモは端末の中だけに保存されます。

## 8. セキュリティ（パスコードと暗号化）

設定で **パスコードロック** をONにすると、2つの保護がかかります。

1. **画面ロック** … アプリを開くたびに4桁の暗証番号（PIN）が必要になります。
2. **本文の暗号化** … メモの本文を、端末の中で「読めない形」に変換して保存します。

### 仕組み（かんたんに）
- PINそのものは保存しません。代わりに **PBKDF2** という方法で「ハッシュ（PINを変換した値）」だけを保存します。
- 暗号化は **AES-256-GCM** という強力な方式を使い、鍵（パスワードのようなもの）はPINから作ります。
- だから、もし端末の保存ファイルを盗まれても、**PINがなければ本文は読めません。**

```
PIN（4桁）─→ PBKDF2で鍵を作る ─→ 本文をAESで暗号化して保存
```

### 注意点 ⚠️
- **PINを忘れると、本文は元に戻せません**（暗号化の性質上、これは仕様です）。
- クラウド（Supabase）に送られるデータは暗号化されていません。
  （※通信はTLSで保護され、他人のメモは見られない仕組み（RLS）になっています）

## 9. バックアップ（エクスポート／インポート）

メニュー → 設定 → データ管理 から使えます。

| 機能 | 内容 |
|------|------|
| **エクスポート** | 全メモを1つの JSON ファイルに書き出す（バックアップ） |
| **インポート** | JSON ファイルからメモを読み込む（同じIDは上書き） |
| **CSV出力** | 表計算ソフト（Excelなど）で開ける CSV 形式で書き出す |

## 10. 開発する人向け：コマンド一覧

ターミナル（コマンドを打つ画面）で実行します。

| やりたいこと | コマンド |
|------------|---------|

## 12. 用語集（わからない言葉が出てきたら）

| 用語 | 意味 |
|------|------|
| **UI** | ユーザーインターフェース。画面のこと。 |
| **データベース（DB）** | データを整理して保存する仕組み。 |
| **クラウド** | インターネット上にあるコンピュータ／保管庫。 |
| **同期（シンク）** | 複数の場所のデータを同じ内容にそろえること。 |
| **オフライン** | インターネットにつながっていない状態。 |
| **暗号化** | データを、鍵がないと読めない形に変えること。 |
| **ハッシュ** | 元に戻せない形に変換した値。パスワードの保存などに使う。 |
| **論理削除** | 実際には消さず「削除済み」の印を付けるだけの削除方法。 |
| **ビルド** | 書いたコードを実行できる形に変換すること。 |
| **マイグレーション** | データベースの設計（列の追加など）を変更すること。 |
