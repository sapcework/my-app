# LumiNote 仕様書（初心者向け）

このドキュメントは、メモアプリ「LumiNote」がどんなアプリで、どういう仕組みで動いているかを、
プログラミング初心者の方にもわかるように説明したものです。

- 公開URL（Web/スマホ）: **https://myluminote.vercel.app**
- リポジトリ: `sapcework/my-app` の `note/` フォルダ

---

## 1. このアプリは何？

**LumiNote** は、シンプルなメモ帳アプリです。有名な「Simplenote」というアプリを参考に作りました。

特徴は次の通りです。

| 特徴 | 意味 |
|------|------|
| **オフライン・ファースト** | インターネットが無くても使えます。書いたメモはまず自分の端末に保存されます。 |
| **クラウド同期** | ログインすると、メモが自動でクラウドに保存され、別の端末でも同じメモが見られます。 |
| **どこでも使える** | ブラウザ・スマホ（PWA）・Windows/Macアプリ（Tauri）で動きます。 |

> **「オフライン・ファースト」とは？**
> 多くのアプリは「ネットにつながっていないと使えない」作りですが、このアプリは逆です。
> 「まず自分の端末に保存 → 余裕があればクラウドにも同期」という順番なので、電波が悪くてもストレスなく使えます。

## 3. 画面の説明

アプリは大きく「**一覧**」と「**エディタ（編集画面）**」の2つに分かれています。
スマホ（縦画面）では、一覧でメモをタップすると全画面のエディタに切り替わります。

```
┌─────────────┬───────────────────────────┐
│  メモ一覧     │   エディタ（編集画面）        │
│             │                           │
│ ≡  [検索...] │  ← 戻る  タイトル    📌  ⓘ  │
│ ─────────── │  ─────────────────────────│
│ 買い物リスト  │  買い物リスト   ← 1行目=太字 │
│  └牛乳 卵    │  牛乳                      │
│ アイデア     │  卵                        │
│ 日記        │  ...                       │
│      [＋]   │  保存済み           [削除]  │
└─────────────┴───────────────────────────┘
```

### メモ一覧（左側）
- **≡（三本線）** … メニューを開く（設定・ゴミ箱など）
- **検索ボックス** … メモを探す
- **＋ボタン** … 新しいメモを作る
- メモをタップ／クリックで編集画面へ。**長押し**でメニュー（ピン留め・削除）。
- 一覧の見出しは**メモの1行目**、その下の薄い文字は2行目以降のプレビューです。

### エディタ（右側）
- 入力欄は**1つだけ**。**1行目が自動でタイトル**（太字＋やや大きく表示）になります。
- **保存はすべて自動**。入力をやめると保存されます（保存ボタンなし）。
- **📌（ピン）** … このメモを一覧の一番上に固定
- **ⓘ（情報）** … 同期状態・更新日・作成日を表示（同期エラー時は「再同期」ボタン）
- **削除** … メモをゴミ箱へ移動
- 何も書かずに戻ると、**空のメモは自動で破棄**されます。

### 一覧に戻る操作（スマホ）
指の届きやすさのため、3通りの方法があります。
1. **← 戻るボタン**（左上・押しやすい大きさ）
2. **Androidの戻る**（ジェスチャー/ボタン）→ 一覧に戻る（アプリ終了しない）
3. **左端から右へスワイプ**（iOSのPWAでも使える）

## 5. 全体の仕組み（アーキテクチャ）

データは次の順で流れます。

```
  あなたの操作
      │
      ▼
 ┌─────────┐   画面（UI）
 │   UI    │   ボタンや文字入力
 └─────────┘
      │
      ▼
 ┌──────────────────┐  保存のまとめ役
 │ StorageProvider  │  「どこに保存するか」を切り替える
 └──────────────────┘
      │
      ▼
 ┌──────────────────┐  暗号化レイヤー
 │ Encrypted層       │  パスコードONなら本文を暗号化
 └──────────────────┘
      │
      ▼
 ┌──────────────────┐  端末への保存
 │ IndexedDB / Tauri │  ブラウザ or ファイルに保存
 └──────────────────┘
      │
      ▼
 ┌──────────────────┐  同期エンジン（裏方）
 │  Sync Engine     │  あとからクラウドへ送る
 └──────────────────┘
      │
      ▼
 ┌──────────────────┐  クラウド
 │   Supabase       │  インターネット上の保管庫（RLSで自分のメモだけ）
 └──────────────────┘
```

### 大事なルール
1. **画面（UI）はクラウドに直接アクセスしない。** 必ず「保存のまとめ役」を通します。
2. **まず端末に保存。クラウド同期はあとから（裏で）。** 起動時の同期もUIをブロックしません。
3. **同期は復号済み（平文）で行う** → クラウドには平文で保存（暗号化は端末内のみ）。

## 6. メモのデータ構造

```ts
type Note = {
  id: string         // メモを区別する番号（自動でつく）
  title: string      // タイトル（＝本文の1行目を自動で保存）
  content: string    // 本文（1行目を含む全文）
  createdAt: number  // 作成日時
  updatedAt: number  // 最終更新日時
  version: number    // 更新回数
  userId?: string    // 誰のメモか（ログイン時）
  pinned?: boolean   // ピン留めしているか
  deleted?: boolean  // ゴミ箱に入っているか（論理削除）
  deletedAt?: number // ゴミ箱に入れた日時
}
```

> **タイトルは本文の1行目から自動生成**されます（Simplenoteと同じ方式）。
> 専用のタイトル欄はありません。一覧・並べ替え・検索のために `title` に1行目を保存しています。

> **削除しても、すぐには消えません（論理削除）。**
> 「削除」を押すと `deleted = true` を立てるだけ。これで別端末にも削除が同期で伝わり、
> ゴミ箱から復元もできます。「完全削除」で初めて物理的に消えます。

## 7. 同期（シンク）の仕組み

「同期」とは、端末のメモとクラウドのメモを同じ内容にそろえることです。

### ルール：Last Write Wins（最後に書いた人が勝ち）
2つの端末で同じメモを編集したとき、**更新日時（updatedAt）が新しい方を採用**します。

### 同期のタイミング（リアルタイムではない）
- **アプリ起動時**：クラウドと照らし合わせ（バックグラウンドで実行、UIは待たない）
- **メモを編集したとき**：2秒待ってからまとめて送信
- **失敗したとき**：時間を空けて自動再試行（1→2→4…最大30秒間隔）。1件の送信は15秒でタイムアウトし、固まりません
- **手動再同期**：エディタの ⓘ → 「再同期」ボタン

> 同期はログイン時のみ。未ログインなら端末内だけに保存されます。
> **ログインしておくと、端末のデータを消しても・機種変更しても、クラウドから復元できます。**

## 8. セキュリティ（パスコードと暗号化）

設定で **パスコードロック** をONにすると、2つの保護がかかります。

1. **画面ロック** … アプリを開くたびに4桁のPINが必要
2. **本文の暗号化** … メモ本文を端末内で「読めない形」にして保存

### 仕組み（かんたんに）
- PINそのものは保存しません。**PBKDF2（20万回）** でハッシュ化した値だけ保存。
- 暗号化は **AES-256-GCM**。鍵はPINから作ります。
- だから端末の保存ファイルを盗まれても、**PINがなければ本文は読めません。**

### 注意点 ⚠️
- **PINを忘れると本文は元に戻せません**（暗号化の性質上の仕様）。
- クラウド側は暗号化していません（通信はTLS、他人のメモはRLSで見えません）。

### アカウント
- 新規登録は無効（**管理者がアカウントを発行**）。ログイン専用です。

## 9. バックアップ（エクスポート／インポート）

メニュー → 設定 → データ管理 から使えます。

| 機能 | 内容 |
|------|------|
| **エクスポート** | 全メモを1つの JSON ファイルに書き出す |

## 10. スマホで使う（PWA）

**PWA**（Progressive Web App）= Webサイトをアプリのようにインストールできる仕組みです。

1. スマホのブラウザで **https://myluminote.vercel.app** を開く
2. メニューから **「ホーム画面に追加」**
3. ホーム画面のアイコンから起動（アドレスバーが消えて全画面）

- **オフライン対応**：一度オンラインで開けば、圏外でもアプリが起動します（Service Workerがアプリ本体をキャッシュ）。
- 更新は自動（オンライン時に最新を取得）。反映されない時はアプリを閉じて再起動。

## 14. 用語集

| 用語 | 意味 |
|------|------|
| **UI** | 画面（ユーザーインターフェース） |
| **PWA** | Webサイトをアプリのようにインストールできる仕組み |
| **同期（シンク）** | 複数の場所のデータを同じ内容にそろえること |
| **論理削除** | 実際には消さず「削除済み」の印を付ける削除方法 |
| **暗号化 / ハッシュ** | 鍵がないと読めない形に変える / 元に戻せない形に変換した値 |
| **LWW** | Last Write Wins。更新日時が新しい方を採用する同期ルール |
| **RLS** | Row Level Security。DBで「自分の行だけ」に制限する仕組み |
| **ビルド / マイグレーション** | コードを実行形に変換 / DB設計の変更 |
