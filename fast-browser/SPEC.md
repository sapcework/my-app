## 1. これは何のアプリか

**軽い・すぐ起動する** ことを一番に考えて作った、Windows 用のシンプルな Web ブラウザです。

Chrome や Edge のような「なんでもできるブラウザ」ではなく、
**Web を見るのに必要な機能だけ**に絞っています。そのぶん動作が軽くなります。

| | fast-browser | 一般的なブラウザ |
|---|---|---|
| アプリ本体のサイズ | 約 9 MB | 数百 MB |
| インストーラー | 約 2〜3 MB | 100 MB 以上 |
| 拡張機能 | なし | あり |
| アカウント同期 | なし | あり |

### なぜ軽いのか

普通、デスクトップアプリで Web ブラウザを作ると **Electron** という仕組みを使います。
これは「アプリの中に Chrome を丸ごと1個入れる」やり方なので、どうしても数百 MB になります。

fast-browser は **Tauri（タウリ）** という仕組みを使っています。
こちらは **Windows に最初から入っているブラウザ機能（WebView2）を借りる** やり方です。
自分で Chrome を持ち歩かないので、アプリ本体が小さくて済みます。

> **WebView2 とは**
> Windows に標準で入っている「Web ページを表示する部品」です。中身は Chrome と同じ技術
> （Chromium）でできています。だから表示の互換性は Chrome とほぼ同じです。

## 2. 動作環境

| 項目 | 内容 |
|---|---|
| OS | Windows 10 / 11（64bit） |
| 必要なもの | WebView2 ランタイム（Windows 11 なら最初から入っています） |
| ウィンドウ初期サイズ | 1280 × 800 ピクセル（サイズ変更可） |
| 表示言語 | 日本語 / 英語（OS の設定に自動で合わせることも可能） |

macOS / Linux でも技術的には動きますが、**現在は Windows のみを対象**にしています。
（OS ごとに借りるブラウザ機能が違うため、表示の細かい差が出ます）

## 3. 画面の見かた

上から順に、こう並んでいます。

```
┌────────────────────────────────────────────────┐
│ ● Google  × │ ● 例のサイト × │  ＋            │ ← ① タブバー
├────────────────────────────────────────────────┤
│ ‹  ›  ↻  │🔒 https://www.google.com │☆ 🕘 ☰ ▾│ ← ② ツールバー
├────────────────────────────────────────────────┤
│                                                │
│              Web ページの中身                   │ ← ③ コンテンツ領域
│                                                │
└────────────────────────────────────────────────┘
```

### ① タブバー

開いているページの一覧です。

- 各タブにはそのサイトの **アイコン（ファビコン）** と **ページのタイトル** が出ます
- 読み込み中はアイコンの代わりに **くるくる回るマーク** が出ます
- `×` を押すとそのタブを閉じます（**タブが1枚だけのときは × が出ません**）
- 右端の `＋` で新しいタブを開きます

### ② ツールバー

| 部品 | 説明 |
|---|---|
| `‹` `›` | 前のページに戻る / 進む |
| `↻` | ページを読み込み直す |
| 🔒 | 鍵マーク。通信が暗号化（https）されていれば表示されます |
| アドレスバー | URL を入れる欄。**URL でない文字を入れると検索になります** |
| ☆ | 今見ているページをブックマークに追加 / 解除 |
| 🕘 | 閲覧履歴パネルの開閉 |
| ☰ | メニューの開閉 |
| `▾` | 検索エンジンの切り替え（Google / DuckDuckGo / Bing） |

> **アドレスバーの賢いところ**
> - `example.com` → そのままサイトへ
> - `今日の天気` → ドットがないので**検索語**とみなして検索
> - `hello world` → 空白があるので**検索語**とみなして検索

### ③ コンテンツ領域

Web ページそのものが表示される場所です。

## 4. できること（機能一覧）

### 4-1. タブ

複数のページを同時に開いて、切り替えながら使えます。

**このアプリで一番こだわっている部分です。**
タブを切り替えても、**そのページの状態がそのまま残ります。**

- 入力途中の文字が消えない
- スクロール位置が戻らない
- 「戻る」ボタンの履歴がタブごとに独立している

一般的なブラウザなら当たり前ですが、これを実現するには
**タブ1枚ごとに表示部品を1つずつ用意する**必要があり、そのぶんメモリを使います。

そこで fast-browser は上限を決めています。

> **同時に生かしておくタブは最大 6 枚**
> 7枚目以降を開くと、**いちばん長く見ていないタブ**の中身をそっと解放し、
> URL だけを覚えておきます。そのタブに戻ると、そのときに読み込み直します。
> タブの見た目は消えないので、普通に使っているぶんには気づきません。
>
> これは Chrome の「タブの休止」と同じ考え方です。
> **今見ているタブは絶対に解放されません。**

### 4-2. ブックマーク

よく使うページを保存しておく機能です。

- ☆ ボタンで追加・解除
- メニューの「ブックマークバーを表示」で、アドレスバーの下に一覧を表示
- 削除しても、画面下に出る通知から **「元に戻す」** で復活できます

### 4-3. 閲覧履歴

見たページが自動で記録されます。

- 🕘 ボタン、または `Ctrl+H` で開閉
- **キーワードで絞り込み**できます（タイトルと URL の両方が対象）
- 「今日」「昨日」のように**日付ごとにまとめて**表示されます
- 1件ずつ削除、または全部まとめて削除。どちらも **「元に戻す」** が使えます
- 同じページを続けて開いた場合は、時刻だけ更新して重複させません
- **最大 1000 件**。それを超えると古いものから消えます

### 4-4. ダウンロード

ファイルのダウンロードに対応しています。

- 保存先は Windows の「ダウンロード」フォルダ
- `Ctrl+J` で一覧パネルを開閉
- 「フォルダを開く」でエクスプローラーが開き、そのファイルが選択された状態になります
- 同名のファイルがある場合は `名前 (1).拡張子` のように連番がつき、**上書きしません**
- **最大 200 件**まで記録

### 4-5. ページ内検索

今見ているページの中から文字を探します。

- `Ctrl+F` またはメニューから
- 見つかった箇所が**黄色**、今選んでいる箇所が**オレンジ**にハイライトされます
- 「3 / 12」のように件数が出ます
- `Esc` で閉じます
- 重いページで固まらないよう、ハイライトは**最大 2000 箇所**まで

### 4-6. ズーム（拡大・縮小）

文字が小さくて読みにくいときに使います。

- `Ctrl` + `+` で拡大、`Ctrl` + `-` で縮小、`Ctrl+0` で 100% に戻す
- メニューからもボタンで操作できます
- **25% 〜 500%** の範囲
- 設定は保存され、**次回起動時も維持**されます

### 4-7. プライベートモード

オンにしている間、**閲覧履歴を一切記録しません。**

- メニューから切り替え
- オンの間はツールバーに **🕶 プライベート** のバッジが出るので、状態を見間違えません
- ※ Cookie やキャッシュは消えません。「履歴を残さない」だけの機能です

### 4-8. 設定

メニューの下部で変更できます。すべて自動保存されます。

| 設定項目 | 内容 |
|---|---|
| ホームページ | 起動時に開くページ。`http://` か `https://` で始まる URL のみ |
| 検索エンジン | Google / DuckDuckGo / Bing |
| 表示言語 | 日本語 / English / OS の設定に従う |
| ズーム倍率 | 上記のズーム操作が保存されます |

> **ホームページに変な値を入れたら？**
> `javascript:` のような危険な形式は受け付けず、自動的に Google に戻します。
> そのとき画面下に「http:// または https:// の URL を指定してください」と出ます。

## 5. キーボードショートカット

**ページを見ているときでも、ツールバーを操作しているときでも、どちらでも効きます。**

| キー | 動作 |
|---|---|
| `Ctrl` + `T` | 新しいタブ |
| `Ctrl` + `W` | タブを閉じる |
| `Ctrl` + `L` | アドレスバーに移動（URL が全選択されます） |
| `Ctrl` + `R` / `F5` | 再読み込み |
| `Ctrl` + `D` | ブックマークの追加 / 解除 |
| `Ctrl` + `H` | 履歴パネル |
| `Ctrl` + `J` | ダウンロードパネル |
| `Ctrl` + `F` | ページ内検索 |
| `Ctrl` + `+` / `-` / `0` | 拡大 / 縮小 / 等倍 |
| `Alt` + `←` / `→` | 戻る / 進む |
| `Esc` | 開いているパネルを1つ閉じる |

**右クリックメニュー**も使えます。これは Windows 標準のもので、
「戻る」「更新」「名前を付けて画像を保存」「印刷」などが日本語で出ます。

## 6. データの保存場所

すべてのデータは、以下のフォルダに **人間が読める JSON 形式**で保存されます。

```
C:\Users\<ユーザー名>\AppData\Roaming\com.fastbrowser.app\
```

| ファイル | 中身 |
|---|---|
| `bookmarks.json` | ブックマーク |
| `history.json` | 閲覧履歴（最大 1000 件） |
| `downloads.json` | ダウンロード履歴（最大 200 件） |
| `settings.json` | ホームページ・検索エンジン・ズーム・表示言語 |

Cookie やキャッシュなど、Web ページ側のデータは別の場所（`AppData\Local` 配下）に
WebView2 が管理しています。

> **バックアップしたいとき**
> 上のフォルダをコピーしておけば、ブックマークと履歴が保存されます。
>
> **設定をリセットしたいとき**
> 該当の JSON ファイルを削除すれば、次回起動時に初期状態に戻ります。
> 壊れたファイルがあっても、アプリは初期値で起動するので動かなくなることはありません。

## 7. 中身のしくみ（少し踏み込んだ話）

### 7-1. 2つの部品でできている

| 部品 | 使っている技術 | 役割 |
|---|---|---|
| **画面まわり**（タブ・ボタン・パネル） | React + TypeScript | 見た目と操作 |
| **中身の処理**（タブ管理・保存・通信） | Rust | 実際の仕事 |

この2つは **「コマンド」** という仕組みでやりとりします。
たとえば `＋` ボタンを押すと、画面側から Rust 側へ「new_tab（新しいタブ）」という
命令が送られ、Rust 側が実際にページを開きます。

用意されているコマンドは全部で 28 個です（タブ操作 8・ブックマーク 4・履歴 4・
ダウンロード 4・ページ内検索 3・設定 2・その他 3）。

### 7-2. Web ページは「別のレイヤー」に描かれている

ここが、このアプリの見た目を左右する**一番大事な制約**です。

Web ページの表示部分は、React で作った画面の**上に、Windows が直接描いています**。
別々のレイヤーなので、**React 側から「ページの上に何かを重ねる」ことができません。**

そのため、メニューや履歴パネル・通知などは

> **上のバーの高さを増やして、Web ページ全体を下に押し下げる**

という方法で表示しています。パネルを開くとページがスッと下がるのは、このためです。

```
パネルを閉じているとき          パネルを開いたとき
┌──────────────┐          ┌──────────────┐
│  ツールバー    │          │  ツールバー    │
├──────────────┤          ├──────────────┤
│              │          │  履歴パネル    │ ← 高さを増やす
│  Web ページ   │          ├──────────────┤
│              │          │  Web ページ   │ ← 押し下げられる
└──────────────┘          └──────────────┘
```

### 7-3. Web ページを信用しない設計

Web ページには、悪意のあるものが混じっている可能性があります。
そこで、ページから届く情報は**すべて疑ってかかる**作りにしています。

| 対策 | 内容 |
|---|---|
| 権限を与えない | ページを表示する部品には、アプリを操作する権限を一切渡していません |
| 文字数を制限 | ページのタイトルは 300 文字、アイコンの URL は 2048 文字まで |
| 形式を制限 | アイコンは `http(s)` と画像データのみ許可。`javascript:` などは拒否 |
| 連打を制限 | ページから来る命令は **0.25 秒に1回**まで（タブの大量生成を防止） |
| 発信元を確認 | キーボード操作は「今見えているタブ」からのものしか受け付けません |
| 保存名を検査 | ダウンロードのファイル名から `../` などを除去し、指定フォルダの外に書き出せないようにしています |

## 8. あえて作っていないもの

「機能が足りない」のではなく、**作らないほうが良いと判断した**ものです。

| 項目 | 理由 |
|---|---|
| 独自の右クリックメニュー | Windows 標準のものが既に日本語で高機能。自作すると劣化します |
| 独自のエラーページ | 標準のエラー画面は原因の説明・エラーコード・再読込ボタンを備えており、置き換えると診断情報が失われます |
| 拡張機能 | 「軽さ最優先」という方針と両立しません |
| アカウント同期 | 同上。データはローカルの JSON のみ |

## 10. 今わかっている制限と、これからの課題

### 制限

- **Windows 専用**（他 OS では表示に差が出るため未対応）
- タブを 7 枚以上開くと、長く見ていないタブは戻ったときに読み込み直しになります
- プライベートモードは「履歴を残さない」だけで、Cookie は消えません
- インストーラーに署名がないため警告が出ます

### 今後やりたいこと

1. **自動更新** — 新しいバージョンを自動で受け取れるようにする
2. **E2E テスト** — 「起動 → URL 入力 → タブ操作」を自動で通しで検証する
3. **アプリ識別子の見直し** — 現在の `com.fastbrowser.app` は macOS 対応時に問題になります
   （ただし変更するとデータの保存場所が変わり、既存のブックマーク・履歴が引き継がれません。
   データ移行とセットで行う必要があります）

## 用語のまとめ

| 用語 | かんたんな説明 |
|---|---|
| **Tauri** | 小さなデスクトップアプリを作るための仕組み。OS のブラウザ機能を借りる |
| **Electron** | 同じ目的の別の仕組み。Chrome を丸ごと同梱するので重い |
| **WebView2** | Windows に標準で入っている「Web ページを表示する部品」。中身は Chrome と同じ技術 |
| **Rust** | 速くて安全なプログラミング言語。このアプリの中身の処理を担当 |
| **React** | 画面を作るための仕組み。このアプリのボタンやパネルを担当 |
| **ファビコン** | サイトごとの小さなアイコン。タブに出るあれ |
| **JSON** | データを保存する形式。メモ帳でも開けるテキスト |
| **LRU** | 「いちばん長く使っていないものから捨てる」という考え方 |
