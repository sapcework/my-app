# FastNote

Android の「高速メモ帳」から移行するための、CSV 抽出ツールとメモアプリ。

| フォルダ | 内容 |
|---|---|
| `tool/` | 高速メモ帳のバックアップを CSV に変換するツール（HTML 1ファイル） |
| `app/` | 置き換え先のメモアプリ（Flutter・Android） |
| `sample/` | 動作確認用のバックアップ（中身はダミー） |

## 移行の手順

**スマホだけで移行する（おすすめ）**

1. 高速メモ帳でバックアップを作る
2. FastNote の「設定 → 取り込む」で、そのバックアップファイル（`FastNotepad_…`）を選ぶ
3. 件数と中身を確かめたら、高速メモ帳のバックアップファイルを消す（暗号化されていないため）

FastNote は通信しないので、スマホの中で読み込んでもメモは外に出ない。
破損チェック（先頭の SHA-1）に一致しないときは、確認画面で警告が出る。

**PC で中身を確かめてから移行する**

1. バックアップを、ネットにつながない PC にコピーする
2. `tool/fastnote-export.html` をブラウザで開き、バックアップを読み込んで「CSV を保存」
3. CSV をスマホに移し、FastNote の「設定 → 取り込む」で選ぶ
4. 取り込めたら、スマホと PC に残った CSV を消す

どちらの方法でも結果は同じになる（テストで確認済み）。同じファイルを2回取り込んでもメモは増えない（ID で判定する）。
高速メモ帳で書き換えたメモは、取り込むデータの更新日時が新しく本文が違えば内容を更新する（フォルダ・☆・色は FastNote 側のまま。FastNote 側が新しければ残す。ごみ箱のメモは変えない）。

## アプリ

- メモは端末内の SQLite だけに保存し、通信はしない（リリース版には INTERNET 権限がない）
- 端末の自動バックアップ・機種変更時の転送にも含めない。機種変更の前には「バックアップを書き出す」で保存する
- 書き出しは2種類から選ぶ
  - **暗号化バックアップ（.fnbak）**：パスワード付き。メモ帳や Excel で開いても読めない。フォルダ・☆なども含む全情報が入る。パスワードは保存しないので、忘れると復元できない
  - **CSV**：暗号化なし。Excel で中身を確かめられる。抽出ツールと同じ列なので、そのまま「取り込む」で復元できる
- 「取り込む」は、暗号化バックアップ・高速メモ帳のバックアップ・CSV を中身で見分ける（暗号化バックアップならパスワードを聞く）
- バックアップの解析（`lib/data/fastnote_backup.dart`）は、抽出ツールの `parseBackup` と同じ処理。形式を変えるときは両方を直す
- 画面の作りは高速メモ帳に合わせている（≡ の横メニュー、フォルダ名のタイトル、アプリの色6色＋ナイトモード、編集画面の ◑ と ⋮）
- 機能
  - 一覧：更新したメモが先頭。☆を付けたメモはさらに先頭に固定。検索（本文も対象。一致した箇所の前後を太字で表示）、並び順（更新／作成／タイトル）
  - まとめて選択：メモを長押しすると選択モード。まとめて☆・色・フォルダへ移動・削除（ごみ箱では元に戻す・完全に削除）。削除は「元に戻す」で全件戻る
  - 横メニュー：フォルダ（長押しで名前の変更・削除）、ごみ箱（空にするまで残る）、新しいフォルダ、色、設定
  - 編集画面：◑ でメモの色、⋮ で ☆・リマインダー・全文をコピー・編集を元に戻す／やり直す・最初へ／最後へ・フォルダへ移動・共有・削除
  - 読むモード：キーボードを出さずに表示する（上のボタンで切り替え）。長いメモを選んでコピーするとき、キーボードがメニューや本文をふさがない。設定で「メモを読むモードで開く」を選べる（初期値は書くモード。新しいメモは常に書くモード）
  - リマインダー：指定した日時に通知（端末内で予約するだけで通信はしない。ロック画面ではタイトルを隠す）
  - 文字サイズ、PIN・パスワード・指紋／顔認証のロック（5回間違えるたびに待ち時間が延びる：30秒→1分→5分→15分→30分）、履歴画面で内容を隠す
  - タブレットなど広い画面では、本文を最大720pxの幅に収めて中央に置く

### ビルド

CI（`.github/workflows/fastnote-ci.yml`）で、FastNote の変更時に `flutter analyze`・`flutter test`・抽出ツールのテストが自動で走る。

```
cd app
flutter test
flutter build apk --release
```

`android/key.properties` が無いときはデバッグ署名でビルドされる（kakeibo と同じ仕組み）。

### CSV の列

`表示順, ID, タイトル, 本文, 更新日時, 更新日時UNIX, 文字色, 背景色, 文字数, リマインダー, 状態`（ここまで抽出ツールと共通）
`, フォルダ, ☆, 削除日時UNIX, リマインダーUNIX`（アプリの書き出しだけに付く）

フォルダは名前で対応づける（取り込み先に同じ名前があればそこへ、無ければ作る）。

### 暗号化バックアップ（.fnbak）の形式

`"FNBK"(4) | 版(1) | PBKDF2 の回数(4) | ソルト(16) | ノンス(12) | 暗号文 | 認証タグ(16)`（数値はビッグエンディアン）

中身は上の CSV を UTF-8 にしたもの。鍵は PBKDF2-HMAC-SHA256（30万回）で作り、AES-256-GCM で暗号化する。ノンスまでのヘッダも認証の対象にしている（`lib/data/encrypted_backup.dart`）。

取り込みで必須なのは「本文」だけ。色は高速メモ帳と同じ `#AARRGGBB`。半分以上透けている文字色・ほぼ透明な背景・白背景は「色なし」として取り込む。

高速メモ帳は、画面で使っていない色の値を保存していることがある（実データの 2023年8月〜2024年3月のメモに薄い紫の背景が入っていた）。そのため高速メモ帳のバックアップを取り込むときは、色を取り込むかどうかを確認画面で選ぶ（初期値は取り込まない）。表示でも、文字と地の色のコントラスト比が 3:1 未満なら黒か白に切り替えて、どんな値でも読めるようにしている。
