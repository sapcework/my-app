# FastNote

Android の「高速メモ帳」から移行するための、CSV 抽出ツールとメモアプリ。

| フォルダ | 内容 |
|---|---|
| `tool/` | 高速メモ帳のバックアップを CSV に変換するツール（HTML 1ファイル） |
| `app/` | 置き換え先のメモアプリ（Flutter・Android） |
| `sample/` | 動作確認用のバックアップ（中身はダミー） |

## 移行の手順

**スマホだけで移行する（おすすめ）**

1. 高速メモ帳でバックアップを作る
2. FastNote の「設定 → 取り込む」で、そのバックアップファイル（`FastNotepad_…`）を選ぶ
3. 件数と中身を確かめたら、高速メモ帳のバックアップファイルを消す（暗号化されていないため）

FastNote は通信しないので、スマホの中で読み込んでもメモは外に出ない。
破損チェック（先頭の SHA-1）に一致しないときは、確認画面で警告が出る。

**PC で中身を確かめてから移行する**

1. バックアップを、ネットにつながない PC にコピーする
2. `tool/fastnote-export.html` をブラウザで開き、バックアップを読み込んで「CSV を保存」
3. CSV をスマホに移し、FastNote の「設定 → 取り込む」で選ぶ
4. 取り込めたら、スマホと PC に残った CSV を消す

どちらの方法でも結果は同じになる（テストで確認済み）。同じファイルを2回取り込んでもメモは増えない（ID で判定する）。

## アプリ

- メモは端末内の SQLite だけに保存し、通信はしない（リリース版には INTERNET 権限がない）
- 端末の自動バックアップ・機種変更時の転送にも含めない。機種変更の前には「CSV で書き出す」でバックアップする
- 書き出した CSV は抽出ツールと同じ列なので、そのまま「取り込む」で復元できる
- バックアップの解析（`lib/data/fastnote_backup.dart`）は、抽出ツールの `parseBackup` と同じ処理。形式を変えるときは両方を直す
- 機能：検索（本文も対象）、並べ替え（手動／更新日時／タイトル）、色分け、文字サイズ、
  PIN・パスワード・指紋／顔認証のロック、履歴画面で内容を隠す

### ビルド

```
cd app
flutter test
flutter build apk --release
```

`android/key.properties` が無いときはデバッグ署名でビルドされる（kakeibo と同じ仕組み）。

### CSV の列

`表示順, ID, タイトル, 本文, 更新日時, 更新日時UNIX, 文字色, 背景色, 文字数, リマインダー, 状態`

取り込みで必須なのは「本文」だけ。色は高速メモ帳と同じ `#AARRGGBB`。透明（`#00……`）と白背景は「色なし」として取り込む。
